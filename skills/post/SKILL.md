# Publish a social post

Use this skill whenever the user asks you to publish, schedule, or cross-post
content to any of the nine supported platforms (TikTok, Facebook, Instagram,
X, LinkedIn, Pinterest, Bluesky, Threads, YouTube).

## Flow

1. **Find the target accounts.** Call `list_social_accounts` first. Filter by
   `platform` if the user named one; otherwise list all and pick by
   `username`/`platform`. Capture the `id` of each account you need.
2. **Preview when stakes are high.** For brand-owned channels or anything
   customer-facing, call `preview_post` with the same payload before publishing
   to surface any platform-specific rendering issues. (Note: preview is a
   forward-looking tool — see the tool description for current SDK support.)
3. **Publish.** Call `publish_post` with `caption`, `social_accounts` (array of
   IDs from step 1), optional `media` URLs, and optional `scheduled_at` (ISO 8601).
4. **Confirm.** The response contains a `status` field (`scheduled`,
   `processing`, `processed`, or `failed`). Report it back to the user.

## Minimum viable call

```json
{
  "caption": "VantageOS 0.4 ships today: fully autonomous orchestrators.",
  "social_accounts": ["acc_01HXY...", "acc_01HXZ..."]
}
```

## Scheduled post with per-platform overrides

```json
{
  "caption": "Launch day is here.",
  "social_accounts": ["acc_x_01", "acc_li_02"],
  "scheduled_at": "2026-05-01T14:00:00Z",
  "media": [{ "url": "https://cdn.elpicorp.com/launch/hero.png" }],
  "platform_configurations": {
    "x": { "caption": "Launch day is here. t.co/..." },
    "linkedin": {
      "caption": "Today we ship VantageOS 0.4. A short thread on why this matters for autonomous systems engineers..."
    }
  },
  "external_id": "launch-0.4-2026-05-01"
}
```

## Guardrails

- **Never publish without explicit user confirmation** when the caption was
  generated by you. Show the final text and the target accounts, then ask.
- **X caps at 280 characters.** If the caption exceeds that and one of the
  targets is an X account, either trim with `platform_configurations.x.caption`
  or split into a thread (future tool).
- **Media must be public.** Post For Me fetches from the URL you provide; S3
  presigned URLs with short TTLs are fine, but private GitHub attachments are not.
- **Scheduled time is UTC.** If the user says "tomorrow at 9am Paris", convert
  to the correct ISO 8601 string with trailing `Z`.
